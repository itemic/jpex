# Game Mode (saved for later)

The first, game-style version of the map quiz: four-choice Name It, Find It with three hearts,
points, streak bonuses, hints (50:50 and neighbourhood zoom), stars, confetti and best scores.

These files are not part of the app target. The live quiz (a calmer, Sporcle-style version) grew
out of them and uses the same file names in `jpex/`. To bring the game back, copy these files over
the ones in `jpex/`; ContentView already opens `GameScreen(game:onClose:)`.
