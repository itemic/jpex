# Germany: states and flag sources

Verified 6 October 2026. All flag files are bundled for offline use. No artwork was generated or redrawn.

## Catalog scope

Germany contains 16 federal states. Names and two-letter abbreviations follow [Destatis’ federal-state directory](https://www.destatis.de/DE/Themen/Laender-Regionen/Regionales/Gemeindeverzeichnis/Glossar/bundeslaender.html); the [Federal Returning Officer](https://www.bundeswahlleiterin.de/service/landtagswahlen.html) also lists all 16. Identifiers use the stable ISO 3166-2:DE codes. German names are stored separately from English display names.

The catalogue uses the public/civil state flag where it differs from a service flag. It does not substitute a government-only service flag simply to add a coat of arms. Bavaria uses its lozenge flag without arms, one of [two equally recognized variants](https://www.bayern.de/der-freistaat/the-free-state-of-bavaria/). Saxony-Anhalt uses the current flag bearing its arms: the [state Interior Ministry](https://mi.sachsen-anhalt.de/themen/wappen-flagge-symbol-siegel-und-landeslogo) explains that this became available to everyone in 2017. The older plain yellow-black bicolour is not used.

## Artwork register

Each linked file page was inspected. Wikimedia Commons’ image metadata identifies all sixteen selected files as public domain official works (`PD-Flag-Germany` or equivalent `PD-GermanGov`), with attribution not required. The public-domain rationale is [§ 5(1), German Copyright Act](https://www.gesetze-im-internet.de/urhg/__5.html), as applied by each source page. This describes the source files’ stated status; flag display conventions are separate. Bavaria’s page additionally offers CC BY-SA 3.0/GFDL, but its public-domain official-work designation is the basis used here. Contributor credits are retained as a courtesy and to make provenance reviewable.

Source proportions are retained, including Thuringia’s 2:1 flag and Bremen’s 3:2 flag; PNG dimensions involve ordinary whole-pixel rounding. Colours and heraldic devices have not been altered.

## In-app credit data

`jpex/GermanyFlagCredits.json` contains the state name, author credit, source page, public-domain designation and supporting licence link for the Settings acknowledgements. Recommended short introduction: “German state flags from Wikimedia Commons, identified by their sources as public-domain official works.” No extra per-state warning is needed in the travel interface.
